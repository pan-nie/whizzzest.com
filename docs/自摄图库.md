# 万载图库

公开图库为 `/gallery/` 和 `/en/gallery/`，入口在主站「旅游」导航。后台地址为 `admin.whizzzest.com/#/gallery`，沿用网站现有的管理员登录。

## 上传和发布

1. 在团队存储中保留原片和授权记录。选择可以公开的照片，确认署名和许可，按需遮挡人脸、车牌或私人地址。
2. 在后台图库点击「上传照片」，填写标题、拍摄地点、摄影署名、替代文本和许可。日期可填 `YYYY-MM-DD` 或 `YYYY-MM`。英文资料选填，缺失字段显示中文原文。
3. 选择「草稿」保存并在后台预览，确认后点击「发布」。已发布照片可以编辑文字和排序，点击「下线」可撤下，点击「删除」清理两个网页副本。若显示「待清理」，可在同一条记录重试。

浏览器读取原片时应用照片方向，生成最长边 2048 像素的大图和 640 像素的缩略图，然后只上传 JPEG 副本。服务端校验图像尺寸、格式和元数据。HEIC 无法被浏览器读取时，可先导出为 JPG。

## 存储与上线

D1 的 `gallery_photos` 表保存资料、状态和 R2 标识。图片存在媒体桶的 `gallery/` 前缀，常规 `/media/` 代理拒绝该前缀。公开图片路由只读取已发布记录，并使用 `Cache-Control: no-store`。后台预览需要管理员会话。

新增环境先执行迁移 [009](../scripts/migrations/009-20261125-gallery.sql)，再部署主站和管理后台。运行 `npm run build` 后可用 `npm run test:gallery` 在隔离的 D1 和 R2 中检查上传、草稿、发布、下线和删除。
